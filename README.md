# Ashen Vow: Bell Chasm

第一人称暗黑奇幻战斗跑酷 Roguelite Demo。玩家通过墙跑、空中冲刺、滑铲跳、奇幻牵引和专注时缓穿越断裂城垣，并在祭坛选择职业构筑，让移动方式与战斗方式共同改变。

## 核心玩法

每次流程由跑酷、遭遇战、祭坛强化和首领机制组成。教学段允许玩家用基础动作熟悉路线，但出口与首领门禁需要职业核心构筑；构筑会打开新的移动衔接、攻击循环和支路解法。

### 影刃

近战职业，以高速接敌、横斩、弹反和处决维持移动节奏。

- 残影回溯：记录位置并回到锚点，用时间裂痕重排进攻路线。
- 弹反决斗：弹回远程攻击、瞬身接近并处决暴露目标。
- 滑铲破阵：从低位规避攻击，以滑铲跳和宽刃横斩破甲。
- 飞檐猎杀：墙跑积累锋势，蹬墙锁敌，空中击杀刷新机动资源。

### 咒行者

远程施法职业，以元素、封印和空间塑形控制路线与战场。

- 元素塑能：火焰范围、寒冰控制、风力滞空和雷电连锁。
- 封印术士：标记敌人与机关，沿路线集中引爆契印。
- 裂隙塑形：生成临时墙面、风井与锚点，主动改造跑酷线路。
- 风暴行者：在墙跑和滞空中积累法力，以连锁法术延长空中循环。

## 操作

| 功能 | 默认输入 |
| --- | --- |
| 移动 | `WASD` |
| 跳跃 / 蹬墙 / 滑铲跳 | `Space` |
| 空中冲刺 | `Shift` |
| 滑铲 | `Ctrl` 或 `C` |
| 攻击 / 施法 | 鼠标左键 |
| 格挡、弹反 / 职业副攻击 | 鼠标右键 |
| 交互 / 瞄准锚点牵引 | `E` |
| 职业技能 | `Q` |
| 切换技能 | `Z` |
| 空中专注时缓 | 按住 `F` |
| 残影回溯 | `G` |
| 从检查点重试 | `R` |
| 暂停 | `Esc` |
| 调试数据 | `F3` |

钩锁是短促的奇幻牵引：瞄准锚点后按一次 `E`，系统完成锁定、瞬间牵引、自动脱离并保留出口冲量；不需要再次松手，也不会把玩家长时间挂在锚点上。出口方向由瞄准方向和锚点的地形联动决定，可直接接墙跑、空中冲刺或落到恢复平台。

钩锁手感参数集中在 `ParkourProfile`。当前收紧基线由拉速 `36 -> 30 m/s`、加速度 `150 -> 110 m/s²`、到点出口上限 `24 -> 18 m/s`、出口抬升 `6 -> 3.5 m/s`、惯性保持 `1.2 -> 0.75 s` 组成；垂直缩放、垂直速度、摆荡转向和总速度上限也可分别调整。

## 运行工程

需要 Godot 4.7.2。

1. 在 Godot 项目管理器中导入 `game/project.godot`。
2. 等待首次资源导入完成。
3. 按 `F5` 启动主场景。

Windows 发布包为 `release/AshenVow-Demo.exe` 单文件，PCK 已内嵌，不需要旁边的 `.pck`。每次发布只更新这个 EXE 与同目录 README；`builds/` 只用于本地临时导出，不进入 Git。
