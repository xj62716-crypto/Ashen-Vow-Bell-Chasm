# Ashen Vow 核心玩法策划案 r4：路线铸成战斗

日期：2026-09-22  
基线：R12 本地发布链（源码整合 `7caf1fe`，发布提交 `981e26b`，验证记录 `d54d5b7`）

本案接在 R12 之后推进。R12 已保留三关垂直路线、同墙连续跑、空中换墙、钩锁锚点、Boss 跑酷破核、两职业八构筑、刀光与血雾反馈。下一批工作的目标是让玩家明确感觉到：路线本身是战斗资源，构筑会改变路线，敌人和 Boss 必须逼玩家移动。

## 一、体验承诺

玩家从地面起步时能力有限，只能利用基础跳跃、墙跑、冲刺、滑铲和短促牵引求生；每次祭坛选择都应新增一条可执行的“移动→攻击→收益”循环。构筑成型后，玩家可以把墙、锚点、敌人、临时表面和暴露核心串成连续路线，形成“跑得快、打得重、还能继续跑”的高峰体验。

不能用站在地面持续平A完成主路线，也不能用单纯加伤害把构筑伪装成质变。每一段主路线必须有至少一个只有跑酷或职业能力能稳定解决的威胁。

## 二、正式一局结构

1. **选择职业与起步**：影刃或咒行者从基础装备开始；普通移动时左手完全隐藏。
2. **首段路线**：用同墙两段、蹬墙、空中冲刺、换墙和滑铲跳建立移动语言。地面恢复线存在，但会牺牲时间、祭坛路径或战斗收益。
3. **第一次祭坛**：提供职业核心。核心必须同时改变一项移动条件和一项攻击/控制条件。
4. **分歧路线**：高线偏墙跑、锚点和空中敌人；低线偏滑铲、近战压力和可破坏机关。两条线在下一座祭坛前汇合，但带回的强化池不同。
5. **精英段**：用敌人的攻击和受击条件测试构筑循环，破机制后进入一次击杀窗口；击杀返还移动资源或创建新的移动节点。
6. **Boss 战**：先在垂直场地破坏跑酷节点上的核心，再获得有限本体攻击窗口。核心复生后，玩家必须重新选择路线。
7. **结算**：显示总时长、分关时长、受击次数、核心破坏次数、探索支路和最终构筑；重新挑战清空上一局构筑。

目标时长：首次完整流程 30–45 分钟；熟练玩家单关 10–15 分钟。这个目标要用正常输入完成，不能用测试传送或直接推进阶段代替。

## 三、移动链与地形关系

### 1. 同墙与换墙

- 同一面墙允许：墙跑 → 蹬墙 → 空中冲刺 → 同墙再次附着；第二次附着仍受同表面段数限制。
- 蹬墙产生短暂换墙窗口。窗口内接触不同墙面时，当前墙面计时和墙段预算刷新，空中链和专注资源保持。
- 换墙时镜头保持玩家的观察方向，不强制拽回墙面；只有真实接触有效墙面才刷新。
- 落地才结束空中链、清除未使用的冲刺返还，并恢复地面资源。

### 2. 锚点与地形

锚点必须声明 `followup_wall`、`followup_landing`、`followup_slide`、`followup_construct` 或 `swing_route` 之一。牵引不是传送：拉入、摆荡、松手、落点和切向速度都要可读。正式锚点至少有一条“拉锚点 → 蹬墙 → 换墙”路径，以及一条失败后的低线恢复路径。

### 3. 滑铲、滑铲跳与专注

- 滑铲解决低位攻击和低拱障碍；滑铲跳必须能接入高台、墙面或暴露核心。
- 空中冲刺主要修正落点、跨越断口和换墙，击杀、弹反或构筑核心可返还一次。
- 专注时缓只服务于多目标、高落差和弹体读招；资源有限，进入/持续/退出使用边缘折射、拖影、音频滤波和清晰的回弹音，不依赖小字提示。

## 四、两职业八构筑的“循环合同”

每条构筑都必须实现三层：基础阶段改变一项规则，核心阶段开启一条路线，关键联动阶段形成可重复的移动收益。每条循环都要有明确输入、目标条件、移动结果、伤害结果和资源结果。

### 影刃

| 构筑 | 循环 | 质变验收 |
| --- | --- | --- |
| 残影/回溯 | 记录路线与攻击 → 回溯 → 残影沿原路径完成裂杀 → 新位置保留换墙节点 | 回溯改变路线解法，不能只是把玩家传回原点 |
| 弹反决斗 | 高速接近 → 弹反弹体 → 沿弹道折跃到射手 → 一击处决 | 弹反成功必须创造新的墙跑/锚点入口 |
| 滑铲破阵 | 滑铲躲高位攻击 → 滑铲跳切入 → 横劈多个暴露核心 | 命中数量影响下一次冲刺或滑铲资源 |
| 飞檐猎杀 | 墙跑积累锋势 → 蹬墙锁定敌人 → 空中处决 → 刷新冲刺 | 敌人是移动节点，脱离墙面后仍能继续链 |

### 咒行者

| 构筑 | 循环 | 质变验收 |
| --- | --- | --- |
| 风暴行者 | 墙跑/滞空产法力 → 空中命中延长机动 → 连锁弹维持滞空 | 命中必须延长路线，而非只提高伤害 |
| 裂隙塑形 | 生成临时墙/锚点/风井 → 改写下一段路线 → 以新表面换墙 | 临时表面有真实碰撞、寿命、可见受力和可拆除状态 |
| 封印术士 | 标记敌人与机关 → 沿路线引爆 → 控制战场 → 处决暴露核心 | 标记顺序影响控制范围或路线开口 |
| 元素塑能 | 选择火/冰/风/雷 → 元素改变运动与受击条件 | 火=范围持续，冰=冻结/滑面，风=浮空/修正，雷=连锁/返还；禁止只换颜色 |

## 五、敌人与 Boss

### 敌人层级

- 普通敌人：一击窗口明确，负责迫使玩家改变高度或方向。
- 精英：至少一种条件受击，能封锁一条路线并暴露另一条路线。
- 小 Boss：拥有两段以上攻击循环，破机制后只给短暂处决窗口。
- 大 Boss：攻击范围覆盖垂直空间，核心位置和攻击方式随阶段变化。

所有敌人必须具备前摇、出手、收势和可打断/可处决条件。敌人模型、攻击形态、受击材质和声音必须互相对应；自动节点存在不算完成，必须有正式路线内的连续录像。

### Boss 三条路线

1. **高墙链**：核心挂在墙体或垂直塔架，玩家需要墙跑、蹬墙、换墙破核。
2. **摆荡链**：核心位于锚点摆荡路径，松手时机决定是否进入本体窗口。
3. **低位链**：核心在低位障碍后，滑铲躲攻击、滑铲跳切入并破核。

核心破坏后本体窗口有限；本体受击结束后场地重新布置，不能退化成平地站桩战。

## 六、视听和界面验收

- 刀光保持沿 `edge_root → edge_tip` 的真实刀身扫掠，亮度只服务于读招，不能遮住刀体。
- 影刃构筑改变刀光外缘颜色、符文流向或短时亮脊；构筑之间不能只换色，基础武器关闭特效仍要可信。
- 血雾从接触点沿切割方向扩散，使用暗酒红/褐红低发光材质，与刀光分层。
- 普通跑动、加速、冲刺和待机左手完全退出；攻击、格挡、施法、蓄力、牵引和明确双手动作自然进出。
- 专注没有依赖小字的特殊 UI：边缘、拖影、音频滤波和时间回弹共同证明状态。
- 音效事件必须绑定真实出手、命中、弹反、破核、牵引和落地，不允许重复绑定或用占位音覆盖正式声音。

## 七、接口与数据约束

所有可调手感保持公开接口：移动速度、墙跑时长与段数、换墙窗口、空中冲刺返还、滑铲速度、钩锁拉速/摆荡、专注倍率与资源、攻击前摇/命中停顿、武器握点、左手显隐/混合权重、刀光宽度/寿命/亮度/符文增益、血雾大小/不透明度/发光、元素强度、敌人预警和核心露出时长。

每个新参数都要有 profile/resource 校验，禁止把调参写死在场景脚本或只在测试夹具里生效。

## 八、实施批次与出口条件

### 批次 A：路线必要性

用正式首关和 Boss 入口做两职业正常输入录像。记录同墙两段、空中换墙、锚点接墙、滑铲跳接高台和失败恢复线。关闭某一移动能力后，必须能证明主路线无法稳定完成或收益显著下降。

### 批次 B：构筑质变

每职业先完成四条构筑的基础→核心→关键联动真实循环；每条至少一段 60–90 秒连续局内录像，包含祭坛选择、能力使用、命中、资源返还和下一次移动。静态祭坛图和自动 API 断言只能作为辅助证据。

### 批次 C：Boss 路线战

把三条 Boss 路线各绑定到真实墙、锚点或低位障碍；记录破核前的跑酷、破核瞬间、本体窗口、场地重布置和下一轮路线。核心不得平放在 Boss 脚边。

### 批次 D：视听收口

逐职业检查刀光、血雾、专注、牵引、破核和落地的连续音画；确认 UI 不遮挡准星和路线，确认 1080p Forward+ 下稳定运行。

### 批次 E：发布

只有 A–D 的正式连续实机证据、自动检查和人工观感均达到要求，才从当前最新提交导出单文件内嵌 PCK EXE。发布必须携带源码提交、哈希、`GDPC` 检查、冷启动记录和 README；禁止从旧提交或干净基线重建。
