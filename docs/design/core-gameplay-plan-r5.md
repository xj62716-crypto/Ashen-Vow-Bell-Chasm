# Ashen Vow 核心玩法策划案 r5：流势铸成时间线

日期：2026-09-22
基线：当前整合工程 `demo-source` 与现有正式 EXE；本文件是下一阶段的设计与实现规格，不表示其中内容已经全部接入或验收。

## 0. 本案解决的问题

当前 Demo 的基础动作、战斗、祭坛和构筑已经存在，但玩家容易感受到“跑一段、平地攻击、选一次强化、继续跑”。本案把跑酷、战斗和局内肉鸽合成一条可重复的行为链，并将用户新增的时间线切换作为路线和战斗的共同变量。

最终体验承诺：

> 移动制造流势，流势改变攻击或空间；攻击创造下一个移动机会；击杀、弹反或破核返还移动/时间资源；玩家在现世与残世之间主动切换，把一段危险路线变成自己的高速战斗路线。

“跑得爽、打得爽、越构筑越像开高达”是目标；单纯增加伤害、换颜色、站在原地平A或等待技能冷却都不能算完成。

## 1. 基线与保留范围

本案以当前正式整合工程为唯一继续开发基线，保留已有内容：

- 第一人称暗黑奇幻方向，参考 Ghostrunner 的速度、路线压力和第一人称反馈，参考《镜之边缘》的空间组织，参考《鼠疫 2》的中古黑暗奇幻材质、敌人和声音厚度。
- 两个职业：影刃（长刀近战）和咒行者（法杖远程/空间法术）；不恢复盾卫玩家职业。
- 墙跑、同墙“墙跑 → 空中冲刺 → 同墙再附着”、蹬墙换墙、滑铲、滑铲跳、钩锁/魔法牵引、专注时缓。
- 两职业各四条构筑：影刃的残影/回溯、弹反决斗、滑铲破阵、飞檐猎杀；咒行者的风暴行者、裂隙塑形、封印术士、元素塑能。
- 祭坛三选一、Boss 跑酷破核、普通/精英/小 Boss/大 Boss 分层、一次受击容错方向。
- 当前已确认的第一人称规则：普通跑动、加速、冲刺和移动待机时左手完全隐藏；攻击、格挡、施法、蓄力、牵引和明确双手动作时自然进入；长刀双手握柄横劈，法杖低位横握携带、施法时转换。

本案不把既有自动检查、静态预览或旧 EXE 当作新系统已完成证据。完成条件仍遵循现有 `QA-v1.6/QA-v1.7` 与 `release-readiness.md`：真实场景、真实输入、连续录像、声音同步、性能和人工观感都要通过后才允许导出下一版 EXE。

## 2. 三位一体的核心循环

### 2.1 四段行为链

每个正式遭遇都要支持以下四段，至少连续发生两次才能称为一个有效循环：

1. **移动制造优势**：墙跑、滑铲、冲刺、摆荡、切换时间线或改变高度，进入敌人的侧面、背面、弱点或安全攻击角度。
2. **攻击转化优势**：利用锋势/咒势进行横劈、弹反、标记、元素控制、处决或空间塑形，攻击必须产生位置变化、弱点暴露或路线节点。
3. **击杀/破机制产生收益**：普通敌人暴露后一击击杀；精英破防后短处决；核心破坏、弹反、有效命中或连续击杀返还冲刺、墙跑、时流或构筑资源。
4. **收益推动下一次移动**：玩家不被无意义的攻击后摇锁在地面，能立即接下一面墙、锚点、敌人节点、滑铲通道或新时间线路线。

### 2.2 失败的设计信号

出现以下任一情况，应视为本案实现失败并回到地图/敌人设计修正：

- 玩家不使用墙跑、滑铲、空中冲刺或时间线也能稳定走完主路线。
- 敌人只作为站桩血包，击杀不改变位置、路线或资源。
- 祭坛只增加伤害/速度，获得核心后 30 秒内看不到新的攻击或路线行为。
- 所有职业和构筑都使用同一个“接近 → 普攻 → 刷冲刺”循环，只是数字不同。
- 时间线只改变颜色、雾气或贴图，不改变可行走表面、敌人防护、攻击方向或路线收益。

## 3. 双流势系统

流势是职业层面的即时玩法资源；时流能量是时间相关的共享资源。两者相关但不能混成一个无法读懂的槽。

### 3.1 影刃：锋势（Edge Momentum）

锋势表示影刃在高速移动和近距离决斗中积累的切入优势。

| 行为 | 初始建议值 | 设计作用 |
| --- | ---: | --- |
| 墙跑持续 | +4/秒 | 鼓励沿墙寻找下一个目标 |
| 空中冲刺穿越危险线 | +8 | 让修正落点也有收益 |
| 滑铲跳穿过高位攻击 | +6 | 将低位规避接到进攻 |
| 弹反成功 | +20 | 用风险换取下一次决斗入口 |
| 有效命中/处决 | +12/+18 | 让攻击推动移动，而非终止移动 |
| 受到伤害或无意义落地停留 | -20/持续衰减 | 防止原地蓄满 |

锋势分为 0–100 三档：低于 35 为普通、35–69 为锐势、70 以上为满势。初始实现只允许同时存在一条主动消耗，避免多个模式叠加造成输入负担。

- 普通横劈：消耗 0–10，保持惯性；击中弱点产生小幅前移。
- 锐势攻击：消耗 25，允许追身横斩、弹反折跃或滑铲破甲中的一种，具体由构筑决定。
- 满势处决：消耗 50–70，锁定已暴露敌人/核心，完成后返还一次冲刺或创建一个短时敌人移动节点。

构筑改变锋势的生成对象、消耗结果和终结方式，不能只改变倍率：

- 残影/回溯：锋势记录路线和攻击意图，回溯后残影执行一次裂杀。
- 弹反决斗：弹反将锋势转成沿弹道折跃，并把射手变成下一个墙跑入口。
- 滑铲破阵：滑铲期间累积锋势，横劈命中数量决定下一次冲刺/滑铲返还。
- 飞檐猎杀：墙跑锋势达到阈值后才能锁定空中处决，处决刷新冲刺。

### 3.2 咒行者：咒势（Spell Momentum）

咒势表示咒行者通过滞空、墙跑、命中和空间塑形建立的施法回路。

- 墙跑/滞空：持续小量生成；落地停留会衰减。
- 远程命中：生成咒势，并延长空中控制或法术连锁窗口。
- 时间线切换：在合法时机切换时获得一次短暂施法稳定窗口，而非免费无脑连续切换。
- 生成临时墙、风井、锚点：消耗咒势，但创建真实碰撞和下一段路线。

咒势的关键不是“更强的炮”，而是把法术转化成空间：

- 风暴行者：命中延长滞空，连锁弹维持下一次墙跑。
- 裂隙塑形：把咒势变成临时墙、锚点、风井或浮台，改变路线。
- 封印术士：标记/引爆改变敌人和机关的控制顺序，打开路线。
- 元素塑能：火、冰、风、雷改变受击、位移和路线状态，禁止仅换颜色。

## 4. 时流能量：专注与时间线切换的共同基础

专注和时间线切换使用同一来源的“时流能量”，但有不同消耗出口；锋势和咒势不被替换为时流能量。

### 4.1 资源规则

- 资源上限：100，正式数值放入 `TemporalTuning` Resource；当前先以 100 做平衡基准。
- 生成：墙跑、空中冲刺穿过危险线、弹反、处决、破核、时间线差异目标和有效法术命中产生时流。
- 禁止生成：站在安全地面等待、菜单停留、暂停、死亡、测试传送。
- 专注：按住固定键持续消耗，世界速度初始 30%–40%，现实持续 0.35–0.60 秒；玩家镜头和瞄准保持自由。
- 时间线切换：一次性消耗 30–35 点，保留玩家位置、视角、水平速度和合法的空中状态；不传送、不自动落地、不清空锋势/咒势。
- 防软锁：关键门槛附近必须有裂隙锚点或一次性应急切换补给；不能让玩家因随机强化或一次误用永远无法切换。
- 恢复：击杀和构筑收益可返还，但有单次和短时间上限；不允许专注常驻或连续无成本切换。

### 4.2 显示与状态

时流能量用一个主环显示，内部区分“可切换段”和“专注可消耗段”；不得再堆多个独立小槽。专注状态不能只靠小沙漏：

- 进入：镜头边缘出现短暂时流折射，配合明确回弹音；
- 持续：边缘符纹、轻拖影和时间比例变化持续可辨，但不遮挡准星、弹体、落点；
- 退出：耗尽、释放、落地、暂停、死亡、重开都清理特效并播放对应收束音。

时间线状态必须同时通过场景材质、敌人姿态/攻击、可行走表面和音频层体现，不能仅改颜色。

## 5. 现世与残世的地图规则

### 5.1 共享骨架、差异图层

每一关不制作两张完全分离的地图，而是在同一空间骨架上提供两层差异：

- **现世**：建筑结构较完整，桥廊、平台和门体稳定；敌人护甲/防守更强，常用于观察和规划。
- **残世**：建筑断裂、漂浮、塌陷或被裂隙重构；出现临时墙、裂隙锚点、风井、暴露核心或不同敌人弱点，常用于快速穿越和高风险捷径。

每个大区至少满足：

1. 一条两时间线都能走的基础恢复路线；
2. 一条切换后明显更快或更安全的主捷径；
3. 一条与职业构筑相关的高收益支线；
4. 一条失败后能回主路的低线恢复路径；
5. 至少一个时间线切换同时改变路线条件和战斗条件的遭遇。

### 5.2 立体地图层级

正式地图采用低线/中线/高线三层，并用内外空间连接：

- 低线：地面街区、滑铲低拱、破坏障碍、重卫和近战压力；
- 中线：桥廊、窗洞、连续墙、侧向锚点、射手和施法者；
- 高线：塔架、外墙、空中敌人、摆荡链、Boss 核心和高收益捷径。

每段地图节点必须拥有可量化的 `entry`、`threat`、`traversal`、`exit` 和 `recovery`，不能只摆一个平台和几只怪。周围要有承重建筑、远景、地标和材质逻辑，避免空中孤岛和突兀白盒。

### 5.3 地图数据结构

建议使用可校验的 Godot Resource/场景元数据：

```text
RouteNode
  id: StringName
  layer: low | mid | high
  timeline_mask: present | ruined | both
  tags: wallrun, slide, grapple, enemy_node, altar, boss_core...
  entry_points: Array[NodePath]
  exit_points: Array[NodePath]
  fallback_route: NodePath
  required_capabilities: Array[StringName]
  reward_profile: Resource

ThreatSlot
  node_id: StringName
  role: hunter | blocker | ranged | caster | anchor_guard | aerial
  preferred_height: low | mid | high
  attack_cones: Array[AttackCone]
  allowed_concurrency: int
  timeline_affinity: present | ruined | both

TimelineVariant
  node_id: StringName
  collision_state: enabled | disabled | fragile
  visibility_state: visible | occluded | revealed
  enemy_modifiers: Resource
  traversal_surfaces: Array[NodePath]
  switch_cost_modifier: float
```

地图编辑验收必须能回答：玩家从哪里进入、为什么要换高低层、敌人在哪个角度施压、打掉敌人后获得什么、失败如何回主路、切换时间线是否改变可行走空间。

## 6. 敌人、位置和 AI 的统一设计

### 6.1 敌人放置不是坐标堆叠

敌人绑定 `ThreatSlot` 和路线职责：

| 原型 | 主要位置 | 攻击如何服务路线 | 破解后收益 |
| --- | --- | --- | --- |
| 誓刃追猎者 | 连接平台/中线 | 突进斩逼玩家侧移、换墙或弹反 | 直接击杀，留下接敌节点 |
| 墓门重卫 | 门口/低线窄桥 | 正面盾压、高位横扫封低线 | 绕后/滑铲诱导后暴露，破后处决 |
| 荆棘弩手 | 侧翼高台 | 射线锁定下一面墙或落点 | 墙跑改线、弹反或趁装填接近 |
| 灯疫异端 | 中线/时间线交界 | 火带、扇形法术、延迟落点改变通行 | 起手打断或穿过间隙处决 |
| 缚钟师 | 锚点/机关旁 | 铃锚封锁牵引和切换路线 | 破坏铃锚、反射攻击或近身打断 |
| 翼骸哨兵 | 高线/空中节点 | 俯冲和投射迫使玩家使用空中移动 | 躲过俯冲后反击，提供影刃移动节点 |

普通、精英、小 Boss、大 Boss 是威胁层级，不是换色变体。普通敌人暴露后一次有效攻击击杀；精英有组合招式和短破防；小 Boss 至少两段攻击循环；大 Boss 通过垂直核心、时间线和场地重布置改变路线。

### 6.2 AI 架构：有限状态机 + Utility + 轻量 GOAP

不建议所有怪物都完整运行 GOAP。使用三层架构：

1. **个体反应层**：普通敌人使用状态机/Utility，状态为 `idle`、`alert`、`reposition`、`telegraph`、`attack`、`recover`、`search`、`stagger`、`dead`。保证前摇、出手、收势和受伤条件确定。
2. **遭遇调度层**：Encounter Director 依据 ThreatSlot 管理同时攻击槽位、视线、玩家所在高度、当前时间线和恢复路线，避免所有敌人一起攻击唯一落点。
3. **高层计划层**：精英、敌群指挥者和 Boss 使用有限动作集的 GOAP/Utility 选择目标：封锁高线、保护核心、抢占锚点、切换时间线、破坏临时墙、压迫落点、搜索最后已知位置、撤回防守点。

GOAP 的世界状态只允许来自可验证传感器：视线、声音、最后已知位置、路线节点、时间线、临时构造、核心状态和可用攻击槽。AI 不读取玩家尚未发生的输入，不瞬间修正已出手攻击的方向。

### 6.3 感知、公平和地形回应

- 有遮挡时只能保留最后已知位置；跑动、施法、击杀和构造会产生声音警觉。
- 近战攻击必须有准备、出手、收势；射手临近发射锁定方向，给冲刺、转向和弹反留下窗口。
- 普通遭遇以“一次主要攻击 + 一次容易识别的辅助威胁”为调参起点，其他敌人移动、换位或瞄准。
- 地面敌人不机械堆在墙下；射手争夺视线；新造的临时墙真实阻挡相应弹体；可破坏构造有明确起手和破坏时间。
- 残影必须影响敌人目标选择；敌人可以对残影出手并落空，不能所有攻击瞬间跟随玩家回溯。
- 专注时敌人、前摇、弹体和恢复遵循同一世界时间比例，退出不能突然连发。

## 7. 八构筑的实现合同

每条构筑都必须有“启动能力 → 核心路线 → 关键联动 → 终结收益”四个层次。基础阶段就能独立使用，不能集齐五个强化后才像一个玩法。

### 影刃

- **残影/回溯**：记录最近 1.2–1.8 秒合法位置与攻击意图；回到自身位置但不复活敌人、不回滚机关/奖励；残影沿原路径吸引敌人或完成一次裂杀；回溯后保留合理速度和路线节点。
- **弹反决斗**：弹反投射物后沿弹道折跃到射手；成功时打开墙跑/锚点入口；未弹反不免费返还资源。
- **滑铲破阵**：滑铲躲高位攻击，滑铲跳切入暴露核心；横劈多个目标，命中数量影响下一次滑铲/冲刺资源。
- **飞檐猎杀**：墙跑积累锋势，蹬墙锁定敌人，空中处决，击杀刷新冲刺；敌人本身是移动节点。

### 咒行者

- **风暴行者**：墙跑和滞空产生咒势；空中命中延长机动；连锁弹把一个目标转成下一次空中路线。
- **裂隙塑形**：快速生成临时墙、锚点、风井或浮台；有合法落点预览、寿命、碰撞、受力、破坏和消散；必须改变实际路线。
- **封印术士**：边跑边标记敌人和机关；按路线顺序引爆；标记顺序改变控制范围、路线开口或敌人暴露。
- **元素塑能**：火为范围/持续，冰为冻结/碎裂/滑面，风为浮空/位移/修正，雷为连锁/返还；精英和 Boss 将控制转为失衡、打断或破防积累，避免全免疫。

### 祭坛选择

- 每次三选一，局内生效；候选池根据职业核心、已选构筑和下一段路线生成。
- 至少一个候选改变当前可执行路线，一个候选改变战斗/攻击，一个候选提供风险收益或生存调整。
- 祭坛后 30 秒内必须出现能直接试出变化的路线或遭遇。
- 基础路线不能因没抽到指定强化而软锁；强化路线提供更快、更安全或更高收益的通路。
- 混搭允许存在，但每条构筑的核心循环必须仍可辨认；切职业、死亡、重开清理残留姿态和效果。

## 8. 音频替换与动态音乐

当前音效被用户判定为难听且不符，后续不以事件清单冒充完成。应先盘点 Godot 工程已有资源，再选择许可清晰、听感一致的资源替换；找不到合适现成资源时再制作/重设计，不强行保留当前音色。

### 8.1 必须分开的事件

- 移动：脚步、墙跑摩擦、蹬墙、滑铲、滑铲跳、落地、冲刺、摆荡/魔法牵引；
- 刀：两种交替横劈挥空、切肉、击甲、挡刀、弹反、处决、破核；
- 杖与法术：横握携带不发声或低摩擦层，蓄力、火/冰/风/雷释放、命中、塑形、封印、消散；
- 敌人：警觉、瞄准、出手、收势、弱点暴露、失衡、死亡；
- 时间线：切换前吸气/裂隙、切换瞬间、现世/残世环境层、专注进入/持续/退出；
- 机关/Boss：锚点锁定、绷紧/松脱、核心破裂、场地重布置。

每个声音绑定真实动画事件或命中信号，攻击声、命中声、停顿和镜头反馈同拍；禁止重复触发、把单一蜂鸣音复制到所有技能或使用测试夹具音频代替正式局内混音。

### 8.2 动态音乐

至少有探索、移动、战斗、精英/Boss 四层同拍音乐；层之间按遭遇状态交叉淡化或增加层，不用突然切歌。现世和残世可以共享节拍但使用不同配器/空间层，时间线切换时保留节拍相位。专注时降低高频和瞬态密度，保留关键命中和危险提示。

## 9. 教学与引导

教学使用空间安排、敌人行为和短提示完成，不用长段文字解释系统。

1. **移动室**：只教跑、跳、墙跑、空中冲刺、滑铲；第一面墙允许同墙再次附着。
2. **锋势/咒势室**：影刃通过墙跑和近距命中积锋势；咒行者通过滞空和命中积咒势；明确展示资源生成和消耗。
3. **首个敌人**：敌人放在必须移动才能取得优势的位置，教学“移动 → 攻击 → 击杀 → 继续移动”。
4. **首次时间线切换**：同一断口在现世和残世各提供不同路线，切换前后同时改变敌人防护或攻击角度。
5. **首个祭坛**：三选一只出现少量有效候选，立刻安排一段能使用该强化的路线。
6. **首次混合遭遇**：一个低线重卫、一个高线射手或空中敌人，让玩家自行决定路线和时间线。
7. **首个精英**：完整验证识别威胁、选择路线/能力、破解、快速击杀、资源返还和下一次移动。

教学提示可跳过；暂停菜单保留简短动作和资源说明。第一次失败后提示应说明失败原因，例如“残世的高墙可接第二段墙跑”，而不是泛化地让玩家升级。

## 10. 实现拆分

### 批次 A：路线与流势垂直切片

在当前 EXE 对应源工程中制作一个低/中/高三层正式片段：一面可连续墙跑的墙、一个断口、一个锚点、一个低拱、一个普通敌人、一个精英敌人、一个祭坛和一个现世/残世切换点。影刃和咒行者各完成一条可录制循环。

出口证据：两职业真实输入录像；锋势/咒势生成与消耗；击杀返还移动或时流；切换改变实际路线和战斗；没有能力时主路明显更难但不软锁。

### 批次 B：地图/遭遇数据化

将路线节点、ThreatSlot、TimelineVariant 和恢复路线写入 Resource/场景元数据；Encounter Director 根据玩家路线层、时间线和可用攻击槽位调度敌人。先接普通敌人和一个精英，不先做全量 GOAP。

出口证据：地图数据检查、敌人位置与攻击方向对照、遮挡/最后已知位置、构造阻挡弹体、敌人不在唯一落点同时叠加不可读攻击。

### 批次 C：GOAP 高层行为

为精英/敌群/Boss 接入有限动作集 GOAP；普通敌人保持状态机。验证墙跑、残影、塑形、时间线切换和玩家失去视线后的搜索/重新发现。

出口证据：计划日志只包含允许动作；AI 不读未来输入；至少三种不同空间职责在同一段地图产生不同响应；失败原因可以从前摇、声音和路线判断。

### 批次 D：双资源、全八构筑和祭坛

在正式关接入时流能量、锋势、咒势和八条循环合同；每条构筑录制 60–90 秒真实遭遇，包含祭坛选择、能力使用、命中、资源返还和下一次移动。

### 批次 E：音频和教学

先替换 Godot 工程中不合格的已有资源，再补缺口；接入动作事件和动态音乐。完成教学首关、跳过/重播、失败提示和教学后的正式入口。

### 批次 F：全量验收与发布

完成正常输入通关、八构筑差异、双时间线、AI、公平性、声音、UI、1080p 性能和发布包冷启动验证；所有适用 QA 有实际证据后，才导出内嵌 PCK EXE，并将 EXE 与 README 放入发布目录/仓库约定位置。

## 11. 可调接口

全部数值放在 Resource/Profile，不写死在场景逻辑：

- 移动速度、跳跃、墙跑持续/段数、同墙续接窗口、换墙窗口、空中冲刺距离/返还、滑铲速度/跳高、牵引拉速/摆荡；
- 锋势/咒势生成、衰减、阈值、消耗、返还和构筑倍率；
- 时流上限、专注倍率、专注消耗、切换成本、应急补给、时间线过渡；
- 攻击前摇、有效窗口、命中停顿、目标吸附、处决锁定、敌人弱点和核心露出；
- AI 感知半径/视角/声音、攻击槽位、计划冷却、前摇、收势和搜索时间；
- 左手显隐/进入退出/混合权重、握点、武器发射点；
- 刀光宽度/寿命/亮度/符文流向，血雾大小/不透明度/发光；
- 音量分类、动态音乐层、时缓滤波和时间线混音。

每个参数新增后要有 Resource 解析/范围校验和至少一项真实场景检查。测试夹具中的临时值不能代替正式运行值。

## 12. 验收清单

- [ ] 同一正式地图存在低/中/高路线，并且每层有明确进入、威胁、移动方式、出口和恢复线。
- [ ] 敌人位置、攻击方向、弱点和撤离路线与对应地图节点匹配。
- [ ] 普通敌人不需要完整 GOAP；精英/Boss 高层计划只使用允许动作。
- [ ] 影刃锋势和咒行者咒势能在 30 秒内形成可辨的攻击/路线变化。
- [ ] 时流能量同时支持专注和时间线切换，切换有保底，专注不能常驻。
- [ ] 现世/残世至少改变一项路线和一项战斗条件，不是纯换色。
- [ ] 没有强化时基础路线能勉强通过，但强化路线明显改变效率、风险或可达性。
- [ ] 训练段完整展示移动→资源→攻击→击杀→资源返还→下一次移动。

- [ ] 两职业八构筑均有连续局内证据，不能以祭坛图、名称或自动节点存在替代。
- [ ] 在全部适用 QA 和 `release-readiness.md` 关闭前不导出新的 EXE。

## 13. 未决项与默认决策

以下项目本案先采用默认值进入垂直切片，实机后再调，不阻塞设计落地：

| 项目 | 默认决策 | 需要实机验证的点 |
| --- | --- | --- |
| 时流 UI | 一个主环，区分切换段与专注余量 | 1080p 下是否一眼可读且不挡准星 |
| 时间线切换键 | 沿用当前固定键，不增加模式轮换 | 与专注、职业技是否冲突 |
| GOAP 范围 | 精英/敌群/Boss 高层；普通状态机 | 计划频率、CPU 和行为可预测性 |
| 地图差异比例 | 共享骨架，30%–40% 节点/敌人/表面变化 | 制作成本、路线可读性和回退线 |
| 锋势/咒势上限 | 100，三档阈值 | 是否出现囤资源不敢用或循环过强 |
| 教学长度 | 前 10–15 分钟内完成基础语言 | 新玩家是否理解而不觉得被拖慢 |
| 音效来源 | 先用 Godot 工程中合格既有资源，再补许可清晰素材 | 人工听感、循环、混音和时缓适配 |

本案不把这些默认值写成最终平衡，也不替用户预先声明美术或声音方案已采用。下一步实现顺序以批次 A 开始，完成垂直切片后再决定是否调整流势名称、资源数值和时间线差异比例。
