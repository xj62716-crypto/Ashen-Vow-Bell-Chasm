# Ashen Vow 核心玩法策划案 r2

## 1. 体验目标

一句话：玩家以第一人称高速穿越暗黑奇幻城垣，在空中把移动资源、敌人弱点和职业能力串成一条连续循环；开局像原始人，拿到祭坛强化后逐步变成能重写路线的高机动战斗机器。

跑酷不是赶路装饰。关键路线必须让玩家在墙跑、空中冲刺、滑铲跳或钩锁之间做选择，战斗收益来自正确的移动，而不是站在地面平A。

## 2. 一局流程

1. 选择影刃或咒行者，进入首段教学路线。
2. 在垂直路线中完成移动教学与小规模遭遇，第一次祭坛给出职业核心。
3. 通过两个有分歧的路线房间：高处墙跑/钩锁路线和低处滑铲/近战路线。路线的选择影响下一次强化池。
4. 在精英房间用构筑循环破解敌人机制，获得核心联动或能力就绪升级。
5. 进入 Boss 立体战场，先沿墙体、锚点和临时表面破坏跑酷中的暴露核心，再短暂攻击本体；核心重新出现后流程再次开始。
6. 结算当前构筑、时间、受击次数和探索支路，允许重开并重新选择职业。

没有职业核心构筑时，出口或 Boss 本体门禁不能完成；强化不是纯数值奖励，而是改变可走路线与可用攻击循环。

## 3. 移动资源与衔接

- 墙跑：同一面墙允许“墙跑 → 空中冲刺 → 墙跑”；更换到另一面墙且未落地时刷新当前墙跑段数和计时，防刷规则只限制同一表面反复重新附着。
- 空中冲刺：击杀、弹反或职业核心可返还一次；冲刺方向由视线和输入共同决定，不能强制把镜头拽回墙面。
- 滑铲/滑铲跳：低位攻击和高位弹体的分工明确；滑铲跳可切入暴露核心或接入钩锁。
- 奇幻牵引：E 瞄准锚点后摆荡，松开时保留切向速度；锚点 metadata 可以指定接墙、接蹬墙、接高台或接临时墙面。
- 专注时缓：F 只在空中/战斗窗口内提供短时减速；进入、持续、退出都必须有明显的奇幻边线、沙漏和空间拖影反馈，不能依赖小字 UI。
- 落地会重置空中链、冲刺返还和墙跑预算；死亡从当前检查点恢复并清除后续临时敌人状态。

## 4. 职业与循环

### 影刃

- 飞檐猎杀：墙跑积累锋势，蹬墙锁定敌人，空中横劈处决，击杀刷新冲刺。
- 返刃决斗：高速接近，右键弹反弹体，沿反弹方向瞬移到射手，一击处决。
- 掠地突袭：滑铲躲过高位攻击，滑铲跳切入，宽幅横斩多个暴露核心。
- 残影回溯：记录短窗口的路线和攻击状态；回溯不是单纯传送，而是让残影沿原路径完成一次裂杀，并返还一次移动资源。

### 咒行者

- 风暴行者：滞空和墙跑积累法力，空中命中延长机动，连锁弹维持滞空。
- 裂隙塑形：生成临时墙面、锚点和风井，改变下一段跑酷表面；临时表面必须有真实碰撞和有效寿命。
- 封印术士：远程标记敌人和机关，沿路线引爆标记，控制战场后处决核心。
- 元素塑能：火焰做范围和持续，冰做冻结/减速，风做浮空和路线修正，雷做连锁；四元素的结构、运动和受击反馈不同，不能只换颜色。

## 5. 肉鸽构筑

每个职业四条方向，每条都有基础、核心、关键联动三阶段；祭坛给出职业相关池与少量通用池。强化分为移动、攻击、控制、资源、风险收益五类，至少两类同时生效才形成质变。

影刃示例：锋势延长墙跑处决窗口、弹反命中生成牵引锚点、滑铲命中扩大破甲扇区、回溯残影在原路径留下可二次蹬墙的节点。

咒行者示例：风暴命中返还浮空、裂隙墙面可被钩锁二次弹射、封印标记沿墙面传播、元素联动把冰面变成滑铲加速面或把火焰变成可见热流墙。

## 6. 地图与遭遇

地图采用 250–350 米主路线、三层高度带、至少两条支路和一个回望地标。空段、落差和真实外部空间必须可读，避免所有内容挤在平地上。

节奏按“教学→压力→喘息/祭坛→混合测试→Boss 前准备→高潮”起伏。普通敌人分为近战压迫、远程封锁、移动追猎、机关支援；精英和小 Boss 具有明确的前摇、出手、收势、可打断窗口和条件受击规则。大 Boss 的核心永远放在跑酷节点上，不能平放在本体脚边。

## 7. 时缓边界

时缓是必要的，但只作为高难度跑酷与多目标战斗的读招工具，不作为常驻增伤。它应帮助玩家看清弹体、选择钩锁松手点、锁定空中处决目标；资源有限，连续使用会降低收益，专注结束后要有明确的音画回弹。

## 8. 开放接口

移动速度、墙跑时长/段数、空中冲刺返还、滑铲速度、钩锁拉速/摆荡、专注倍率与资源、武器握点、左手显隐/混合权重、攻击前摇/命中停顿、刀光宽度/寿命、血雾大小/不透明度、元素强度和敌人预警时间均通过 profile/resource 或公开 tuning 字段调整。

## 9. 当前落地与下一批

已落地源码：首关延长与垂直平台、锚点接墙 metadata、职业重选清理、Boss 核心门禁、敌人分层基础、墙跑/冲刺/滑铲/钩锁基础、刀光和血雾事件入口。

本批修复：刀光带状网格闭合与加法混合、命中血雾云层、换墙未落地刷新墙跑预算、单文件发布目录。

侧栏下一批按以下顺序推进：

1. 用实际连续输入验证两职业的墙跑→空中冲刺→换墙/同墙再附着，记录墙体、计时和落地重置。
2. 在正式 Boss 场景将核心节点绑定到垂直跑酷路径，并验证破核心后本体窗口。
3. 逐条把八构筑的祭坛选择接到可玩的移动/攻击质变，保留基础无强化时的锁定门禁。
4. 完成普通/精英/小 Boss/大 Boss 的攻击机制和受击条件实战回归。
5. 以正式流程检查专注、刀光、血雾、钩锁、音乐和 UI 的读秒/混音/遮挡。
