# Ashen Vow 核心玩法策划案 r3

日期：2026-09-21

## 本轮目标

把“墙跑 → 蹬墙 → 空中换墙”从偶发技巧变成关卡的可靠基础设施，同时让刀光沿真实刀身扫掠，清楚表现横劈的方向、长度和命中点。玩家的判断顺序应是：先找路线，再选落点，最后用职业构筑把路线转成击杀收益。

## 移动核心链

### 墙跑转场

1. 同一墙面最多连续消耗两个墙跑段；同一表面再次附着仍受段数限制。
2. 每次蹬墙都会留下短暂的“换墙窗口”。窗口内检测到不同墙面时允许正面接近并重新锁定，不要求玩家先落地，也不要求把镜头强行转回墙面。
3. 换到不同墙面后，墙跑段数和当前墙面计时刷新；空中链、冲刺和专注资源不因换墙被清空。
4. 落地才结束空中链并恢复完整资源。普通跳跃没有换墙窗口，避免平地跳直接吸附墙体。
5. 设计一条可读的标准路线：墙跑一段 → 蹬墙回同墙 → 第二段 → 蹬墙/空中冲刺 → 另一墙 → 钩锁或滑铲跳。任何一段失败都要有下层恢复路线，但收益明显降低。

### 钩锁与地形

锚点不作为孤立的传送按钮。每个锚点声明目标地形关系：接蹬墙、接高台、接滑铲入口、接临时墙或摆荡跨越。释放时保留切向速度，锚点之间应能组成“拉锚点 → 蹬墙 → 换墙”的连续动作。锚点摆放必须和支撑结构、灯光和远景地标一致，禁止悬空调试点。

### 滑铲、空中冲刺与专注

- 滑铲处理低位危险，滑铲跳处理低位进入高台或暴露核心。
- 空中冲刺优先用于跨墙和修正落点，击杀、弹反或职业核心可以返还一次。
- 专注时缓只在多目标/高落差窗口使用，进入和退出用边线、拖影、音频滤波反馈，不依赖小字提示；资源有限，不能常驻增伤。

## 战斗与构筑

### 影刃

- **飞檐猎杀**：墙跑积累锋势，换墙或蹬墙后锁定暴露敌人，空中横劈处决并刷新一次冲刺。
- **返刃决斗**：高速接近，弹反弹体后沿其方向瞬移到射手，处决后把落点变成下一次墙跑入口。
- **掠地突袭**：滑铲躲过高位攻击，滑铲跳切入，横劈多个暴露核心；命中数量影响下一段移动资源。
- **残影回溯**：记录短窗口路线和攻击，回溯时残影沿原路径完成裂杀并保留新的换墙节点；回溯是路线重写，不是单纯瞬移。

### 咒行者

- **风暴行者**：滞空/墙跑产生法力，空中命中延长机动，连锁弹把敌人变成空中落点。
- **裂隙塑形**：生成有寿命、有碰撞的临时墙、锚点和风井，主动创造下一面可换的墙。
- **封印术士**：沿路线标记敌人与机关，经过标记时引爆并打开核心窗口；标记顺序影响控制范围。
- **元素塑能**：火是范围和持续，冰是冻结与滑面，风是浮空与路线修正，雷是连锁与资源返还。差异来自结构、运动、受力和受击条件，不能只换颜色。

每条构筑都有基础、核心、关键联动三阶段。祭坛优先给出会改变操作的能力，其次才是数值；没有职业核心时，部分高收益路线和 Boss 核心窗口保持关闭，让玩家感到“构筑是通关工具”而不是结算数字。

## 遭遇与 Boss

普通敌人负责逼迫移动，精英负责改变路线，小 Boss 负责制造短循环，大 Boss 负责把整张地图变成战斗场。敌人必须有明确的前摇、攻击手段、条件受击和破机制后一击必杀窗口。

Boss 核心不放在脚边。核心应挂在墙体、垂直塔架、摆荡路径或临时表面上，玩家在跑酷中破开核心，随后获得短暂本体攻击窗口；核心重新生成后流程再次开始。Boss 战至少包含一条高墙链、一条钩锁摆荡链和一条低位滑铲链，三条链分别对应不同构筑偏好。

## 视觉与反馈验收

- 刀光使用真实 `edge_root → edge_tip` 扫掠面，亮部覆盖刀身中段和刃脊，不能集中成刀尖光标。
- 命中血雾从接触点沿切割方向扩散，和刀光分层，不能被刀光吞掉。
- 每次横劈至少能读到起手、加速、命中、收势四个阶段；音效、相机冲击和时缓都绑定真实事件。
- 左手普通移动完全隐藏，只在攻击、格挡、施法、牵引和明确双手动作中自然进出。
- 所有速度、墙跑时长/段数、换墙窗口、钩锁拉速、专注倍率、刀光宽度/寿命、命中停顿和血雾参数保持公开接口。
