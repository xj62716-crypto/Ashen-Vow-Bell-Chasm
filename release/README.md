# Ashen Vow Demo

这是 Windows 单文件发布包。PCK 已内嵌在 AshenVow-Demo.exe，不需要额外的 .pck 文件。

运行方式：双击 AshenVow-Demo.exe。首次启动可能需要几秒加载资源。

操作：WASD 移动，Space 跳跃/蹬墙，Shift 空中冲刺，Ctrl 或 C 滑铲，鼠标左键攻击/施法，鼠标右键格挡/副职业动作，E 奇幻牵引，F 专注时缓，G 影刃回溯，Esc 暂停。

当前发布包包含两职业、三段垂直跑酷路线、墙体换墙与连续墙跑、短促钩锁牵引与地形锚点联动、祭坛强化、敌人分层和 Boss 核心路线机制。影刃刀光沿真实刀身扫掠，并按四条影刃构筑改变符文外缘与就绪脉冲；命中血雾采用暗酒红/褐红低发光材质。

本包构建自当前整合工作区。本轮钩锁按 Ghostrunner 参考收敛为短促高速直线牵引：一次按键完成出钩、锁定、自动脱钩，不要求松手，也不进入长时间摆荡；保留墙体和后续锚点衔接。旧的循环摆荡音效已移除，改为抛出、锚定、脱钩三段反馈；链条改为冷蓝符文能量线，收紧时亮度提高。第一段出口已落在最终平台内侧，PCK 与本次源代码一致。
