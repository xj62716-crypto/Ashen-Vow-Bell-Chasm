# Ashen Vow Demo

运行 `AshenVow-Demo.exe`。PCK 已内嵌，无需单独放置资源包。

本版保留此前的玩法、音效、羊皮卷职业界面和时间线碰撞优化，并修复影刃在空中跑酷后普通挥刀偶尔自动发射剑气的问题。只有获得离刃、成功弹反后获得返锋剑气，或触发掠地刃风时才会发射对应远程攻击。画面质量与 120 Hz 物理频率未调整。

第一关入口短时采样：RTX 3060 Laptop GPU、Vulkan Forward+、1920 x 1061，现世约 78 FPS，残世约 64 FPS。该结果不代表全关卡或 Boss 战帧率。

影刃远程触发回归 48 项、构筑 32 项、残影 5 项及职业生命周期 24 项通过；更新后的内嵌 PCK EXE 冷启动通过。
