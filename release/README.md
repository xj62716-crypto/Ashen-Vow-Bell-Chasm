# Ashen Vow Demo

这是 Windows 单文件发布包。PCK 已内嵌在 AshenVow-Demo.exe，不需要额外的 .pck 文件。

运行方式：双击 AshenVow-Demo.exe。首次启动可能需要几秒加载资源。

操作：WASD 移动，Space 跳跃/蹬墙，Shift 空中冲刺，Ctrl 或 C 滑铲，鼠标左键攻击/施法，鼠标右键格挡/副职业动作，E 奇幻牵引，F 专注时缓，G 影刃回溯，Esc 暂停。

当前发布包包含两职业、三段垂直跑酷路线、墙体换墙与连续墙跑、钩锁摆荡与地形锚点联动、祭坛强化、敌人分层和 Boss 核心路线机制。影刃刀光沿真实刀身扫掠，并按四条影刃构筑改变符文外缘与就绪脉冲；命中血雾采用暗酒红/褐红低发光材质。

本包构建自完整整合提交 7caf1fe。本轮没有从旧基线回退，上一版未提交的关卡、Boss、环境、钩锁、回溯和存档改动已与本轮刀光/血雾调整一起纳入。
